# NFTWorld Marketplace App

A guided project to render digital creative assets sourced from numerous API sources, freelance animations, slideshows.  Providing links to creators and owners and option to increase followership. Attention to responsiveness, loading states.

---

## 🚀 Features

* **Landing Page:** Subtle animations welcome user while API is loaded in the background and categories of assets are loaded in to their carousel slideshows and tables. Watch for the countdown timer on special items.
* **User Options:** Choose an item and see who created it, owns it and other information. Choose a creator and see what else they have created. Choose an owner and see their ownership portfolio.
---

## 🛠️ Tech Stack

* **Framework:** React
* **Language:** JavaScript (ES6+)
* **Styling:** HTML, CSS (Responsive & Utility Design)
* **API Management:** Accessing objects from 6 different URLs and linking them to the correct category using Axios
* **Slideshow Carousel:** Slider carousel library

---

## ⚙️ Getting Started

### Prerequisites

Ensure you have **Node.js (v18.x or higher)** and npm/yarn installed locally.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/HiraniDotCom/MSH-NFT-World-App
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run start
   ```

4. Open http://localhost:3000 in your browser to see the dashboard.
